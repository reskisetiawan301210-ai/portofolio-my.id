# Reski Setiawan - Portfolio

Website portfolio profesional untuk Reski Setiawan, Software Engineer / Web Developer.

## Stack Teknologi

- **Framework**: React.js (JSX)
- **Build Tool**: Vite
- **Styling**: Modern CSS & CSS Variables
- **Target Deployment**: Vercel

## Menjalankan Proyek

1. Masuk ke direktori proyek:
   ```bash
   cd reskisetiawan-portfolio  # atau nama folder proyek di komputer Anda
   ```

2. Jalankan server pengembangan:
   ```bash
   npm run dev
   ```

3. Build untuk produksi:
   ```bash
   npm run build
   ```
